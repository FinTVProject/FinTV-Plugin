FinTV

Connect this Jellyfin server to FinTV Server. Channels, lineups, and streaming are managed in the FinTV Web UI.

Must resolve from the Jellyfin container, e.g. http://fintv-server:8097 on the same Docker network, or a LAN IP like http://192.168.1.2:8097.

Open the FinTV Server Web UI (port 8097) to manage channels. Catalog metadata syncs on a schedule or from Dashboard → Scheduled Tasks → FinTV Catalog Sync.
