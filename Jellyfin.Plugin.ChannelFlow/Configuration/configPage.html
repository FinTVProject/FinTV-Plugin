ChannelFlow-Jellyfin

Connect this Jellyfin server to ChannelFlow Server. Channels, lineups, and streaming are managed in the ChannelFlow Web UI.

Must resolve from the Jellyfin container, e.g. http://channelflow-server:8097 on the same Docker network, or a LAN IP like http://192.168.1.2:8097.

Adds a ChannelFlow M3U tuner and XMLTV guide under Dashboard → Live TV, using the Server URL above so Jellyfin can reach ChannelFlow.

Send libraries first so they appear in the ChannelFlow Web UI. Pick TV/movie/music libraries there, then use Sync catalog now. Catalog sync sends only those libraries, not the entire Jellyfin server.
